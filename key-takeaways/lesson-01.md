Playwright là 1 automation testing framework ra đời vào 31/01/2020, tiền thân là Puppeteer được Microsoft tài trợ và phát triển

NVM = Node Version Control là 1 công cụ quản lý phiên bản Nodejs

Git là công cụ quản lý các phiên bản code

Github là nơi chia sẻ, lưu trữ code (repository)

Command tạo project Playwight mới: npm init playwright/latest
